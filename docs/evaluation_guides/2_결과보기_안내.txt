2. 평가 결과를 메모장으로 보기
사용할 명령어: 2_결과보기_명령어.txt
준비할 파일: 1번 평가에서 새로 만들어진 reports\new-test-여러문자.json

============================================================
[1단계] 결과 보기 명령 실행
============================================================
1. 앱 폴더에서 CMD를 엽니다. 이미 열어둔 창이면 그대로 사용합니다.
   새로 열 때는 start_learning.bat이 보이는 폴더에서 Ctrl+L → cmd → Enter입니다.
2. 2_결과보기_명령어.txt를 메모장으로 엽니다.
3. Ctrl+A → Ctrl+C로 명령어 파일 전체를 복사합니다.
4. CMD에 붙여넣고 Enter를 누릅니다.

확인: 평가 보고서 JSON을 고르는 창이 뜨면 완료입니다.

============================================================
[2단계] 이번 평가 보고서 선택
============================================================
1. 앱 폴더의 reports 폴더로 이동합니다.
2. 방금 평가할 때 표시된 new-test-여러문자.json을 고릅니다.
3. '열기'를 누릅니다.

이번에 만든 정확한 파일명을 확인하세요.
이전에 만든 compare-...json을 열면 그 예전 평가 결과가 나옵니다.
이 창에서는 평가 JSON을 고릅니다. manifest.jsonl이나 history.json이 아닙니다.

확인: 메모장이 자동으로 열리고 '평가 결과'와 샘플 문장이 보이면 완료입니다.
이 명령은 보고서만 읽습니다. 음성 인식을 다시 실행하지 않습니다.

============================================================
[해석 1] 맨 위 숫자 읽기
============================================================
원본 Whisper small CER:
기본 모델로 이번 평가 녹음을 인식한 문자 오류율입니다.

학습 모델 CER:
선택한 best 모델로 같은 녹음을 인식한 문자 오류율입니다.
낮을수록 좋습니다. 100에서 CER을 뺀 값을 정확도라고 부르지는 않습니다.
전체 오류 수를 전체 정답 글자 수로 나눈 값이며 문장별 점수의 단순 평균은 아닙니다.
표시는 소수 둘째 자리 반올림이므로 같은 표시값에도 작은 차이가 있을 수 있습니다.
정밀한 회차 비교는 3번 안내를 사용하세요.

이번 평가 녹음 수:
이번 보고서의 음성 파일 개수입니다. 1개면 그 녹음 하나의 결과입니다.
더 넓은 성능을 보려면 다양한 평가 녹음이 필요합니다.

학습 자료 수 / 검증 자료 수:
그 모델을 만든 회차에 사용한 파일 수입니다. 이번 평가 파일 수와는 다릅니다.

선택된 epoch / step:
최종 best로 채택된 시점입니다. 전체 진행 횟수는 4번 안내에서 확인합니다.
0 / 0이면 이번 실행의 시작 모델이 best로 남았습니다.
이어 학습이었다면 시작 모델은 이전 어댑터일 수 있습니다.
0 / 0만으로 학습이 실행되지 않았다고 판단하지 않습니다.

============================================================
[해석 2] 샘플별 정답과 인식 문장 읽기
============================================================
음성: 실제 평가한 파일 경로입니다. 의도한 시험용 녹음인지 확인할 수 있습니다.
세션: 녹음을 묶은 이름입니다. 예: test001
언어: 한국어 ko, 영어 en 등의 설정입니다.
정답: 사용자가 듣고 입력한 실제 발화입니다.
원본: 원본 Whisper small의 인식 문장입니다.
학습: 선택한 학습 모델의 인식 문장입니다.

1. 정답과 원본을 비교합니다.
2. 정답과 학습을 비교합니다.
3. 원본과 학습이 서로 다르게 인식한 부분도 확인합니다.

CER에서는 공백·문장부호·대소문자 차이를 제외합니다.
예: '오늘 방송 시작합니다'와 '오늘 방송 시작합니다.'는 같은 것으로 셉니다.
글자를 빠뜨리거나 다른 글자로 바꾸거나 추가한 것은 오류입니다.
CER이 같아도 틀린 문장이 서로 바뀔 수 있습니다.
'인식 문장이 달라진 녹음 수'는 문장부호나 공백만 달라도 셀 수 있습니다.

정답이 의심되면 다시 들어 실제 발화와 맞는지 확인합니다.
정답·언어를 정정했다면 두 모델을 같은 정정 자료로 다시 평가합니다.

============================================================

학습 진행은 '4_학습기록보기_안내.txt'에서 확인합니다.

전체 오류율이 같은 것입니다. 어떤 오류가 줄거나 늘었는지 샘플을 확인하세요.
