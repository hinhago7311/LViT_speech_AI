LViT 새 검증 녹음 연결하기
Windows 메모장용 / 한 단계가 끝나면 다음 단계로 넘어가세요.

기존 학습·검증·평가 배정을 유지하고, 별도 폴더의 새 검수 녹음을 검증용에 추가합니다.
세션 이름을 val001로 정하는 것만으로 검증용에 배정되는 것은 아닙니다.

============================================================
[1단계] 수정본 덮어쓰기
============================================================
1. 학습 중이면 중지하고 종료될 때까지 기다립니다.
2. 현재 목록의 '초안·검수 자료 일괄 저장'을 누릅니다.
3. 앱과 실행창을 닫습니다.
4. 수정본 ZIP을 start_learning.bat이 있는 기존 앱 폴더에 풉니다.
5. 같은 파일을 바꿀지 물으면 덮어쓰기를 선택합니다.
6. 기존 start_learning.bat을 실행합니다.

확인: 학습 실행 영역에 '검증 폴더 연결' 버튼이 보이면 적용됐습니다.
기존 data, .venv, 모델, 평가 보고서는 그대로 유지합니다. 패키지 재설치는 필요 없습니다.
새 폴더에 앱을 다시 설치하는 과정이 아닙니다.

============================================================
[2단계] 새 검증 녹음과 정답 저장
============================================================
이미 별도 폴더에서 검수·저장까지 마쳤다면 [3단계]로 넘어가세요.

1. '다른 폴더 열기'로 별도 검증 폴더를 엽니다.
   예: 바탕화면 → sample → validation_sample
2. 파일 추가 전에 세션을 정합니다. 예: val001
3. 언어를 ko 또는 en으로 정하고 새 녹음을 추가합니다.
4. 실제 발화에 맞는 정답을 적고 검수 완료를 체크합니다.
5. '초안·검수 자료 일괄 저장'을 누릅니다.

확인: 검증 폴더에 manifest.jsonl이 만들어지면 저장됐습니다.
이 폴더에서는 학습 점검이나 학습 시작을 누르지 않습니다.
검수된 항목만 연결 대상입니다. 파일당 30초 이하입니다.
같은 원본의 조각이나 필터 변형은 같은 세션으로 묶습니다.
새 검증 자료에는 이전 학습 자료나 최종 시험용 자료를 재사용하지 않습니다.

============================================================
[3단계] 원래 학습 폴더로 돌아가기
============================================================
1. 앱 맨 위의 '다른 폴더 열기'를 누릅니다.
2. 기존 앱 폴더 → data → my-voice를 선택합니다.
   다른 학습 자료 폴더를 쓰셨다면 그 폴더를 선택합니다.

확인: 원래 학습 목록이 보이고 기존 분할·이전 모델 연결이 유지되면 완료입니다.
이 기능은 이미 학습한 프로젝트의 검증 자료를 확장할 때 사용합니다.
분할이나 모델이 없다는 메시지가 나오면 자료 폴더가 맞는지 먼저 확인하세요.
필요하면 '기존 분할 선택'과 '이전 모델 선택'에서 실제 이전 결과를 지정합니다.

============================================================
[4단계] 검증 폴더 연결
============================================================
1. 학습 실행 영역의 '검증 폴더 연결'을 누릅니다.
2. 앞에서 검수·저장한 validation_sample 폴더로 이동합니다.
3. '폴더 선택' 또는 '확인'을 누릅니다.

이 창에서는 폴더를 고릅니다. 안의 manifest.jsonl을 자동으로 읽습니다.
기존 자료와 겹치는 음성·세션과 모델 이력에 기록된 학습·평가 자료를 검사합니다.
검사가 끝날 때까지 기다려주세요.

확인할 것:
- 학습 개수와 평가 개수는 기존대로입니다.
- 검증 개수는 기존 검증 + 새 검수 녹음 수입니다.
- 연결 경로와 세 가지 개수가 로그와 상태에 표시됩니다.
- 연결 버튼 자체는 모델을 훈련하지 않습니다. 기존 모델을 유지합니다.
- 원래 목록에 새 검증 행이 보이지 않아도 정상입니다.
  별도 폴더를 연결하므로 합산 개수는 연결 로그에서 확인합니다.

취소하거나 검사에 실패하면 기존 연결을 유지합니다.
오류가 나면 기존 분할을 지우거나 전체를 무작위로 다시 나누지 마세요.
오류에 표시된 중복 음성·세션·검수 상태·경로를 먼저 확인합니다.

============================================================
[5단계] 확장한 검증 기준으로 학습
============================================================
1. 원래 학습 폴더에서 장치를 확인합니다.
2. 필요한 경우 '1단계 학습 점검'으로 실행 상태를 확인합니다.
3. 본학습은 '학습 시작'으로 진행합니다.

연결한 새 검증 녹음은 가중치 훈련에 넣지 않고 best 선택에 사용합니다.
새 prepared와 학습 결과를 만들며 이전 분할·모델은 덮어쓰지 않습니다.
연결 경로는 프로젝트에 저장되어 다음 실행과 학습에도 이어집니다.

============================================================
[해석] 검증 CER이 달라졌다면
============================================================
검증 자료를 추가하면 글자 수와 난도가 달라집니다.
확장 전 점수와 확장 후 점수를 바로 학습 전후 성능으로 비교하지 않습니다.

이번 학습의 history.json에서:
- epoch 0: 확장한 검증 자료로 시작 모델을 측정한 값
- 이후 epoch: 같은 확장 자료로 학습한 모델을 측정한 값
이 값들을 비교하면 같은 기준에서의 변화가 보입니다.

검증 CER이 더 낮아져야 best를 교체합니다. 동점이면 이전 best를 유지합니다.
검증을 늘렸다고 인식 정확도가 자동으로 좋아지는 것은 아닙니다.
더 다양한 발화에서 모델을 비교·선택할 기준을 넓히는 작업입니다.

학습 진행 기록 해석은 기존 평가 안내 묶음의 4_학습기록보기_안내.txt를 참고하세요.
최종 시험용 test001은 계속 별도로 유지합니다.
시험용 전후 비교는 같은 평가 음성으로 평가 안내 1~3번을 사용합니다.

============================================================
[보관] 다음에 검증 녹음을 더 추가할 때
============================================================
같은 validation_sample 프로젝트에 새 세션으로 녹음을 누적하고 검수·저장합니다.
원래 학습 프로젝트에서 다시 연결하거나 다음 학습을 실행하면 반영됩니다.
이미 연결한 검증 음성과 세션은 계속 포함되어야 합니다.
정답·언어를 고치면 다시 검수 완료한 뒤 저장합니다.

검증 폴더와 그 안의 audio는 이동하거나 삭제하지 마세요. 학습 때 다시 읽습니다.
위치를 바꿨다면 같은 자료를 담은 새 위치로 다시 연결해야 합니다.
