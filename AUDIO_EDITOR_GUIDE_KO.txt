LViT 음성 편집기 사용법
긴 녹음에서 필요한 구간을 잘라 저장하고 현재 목록에 추가합니다.
한 단계가 끝나면 다음 단계로 넘어가세요.

============================================================
[1단계] 기존 앱에 덮어쓰기
============================================================
1. 현재 목록을 '초안·검수 자료 일괄 저장'으로 저장합니다.
2. 학습 중이면 중지하고 종료될 때까지 기다립니다.
3. 앱과 실행창을 닫습니다.
4. 수정본 ZIP을 start_learning.bat이 있는 기존 앱 폴더에 풀고 덮어씁니다.
5. 기존 start_learning.bat을 실행합니다.

확인: 상단에 '음성 편집기' 버튼이 보이면 적용됐습니다.
기존 data, .venv, 모델, 검증 연결은 유지됩니다. 추가 패키지 설치는 필요 없습니다.
이 수정본은 학습 프로그램의 편집 기능만 추가합니다.
LViT와 보류 중인 표정·단축키 기능은 변경하지 않습니다.

============================================================
[2단계] 어느 자료 폴더에 추가할지 확인
============================================================
학습용 녹음을 추가하려면 원래 data\my-voice 자료 폴더를 엽니다.
별도 검증·평가 자료를 준비한다면 해당 자료 폴더를 먼저 엽니다.
편집기에서 '현재 목록에 추가'하면 지금 열린 자료 폴더에 들어갑니다.

확인: 앱 맨 위 '자료 폴더'가 의도한 폴더인지 확인합니다.

============================================================
[3단계] 긴 원본 녹음 열기
============================================================
1. '음성 편집기'를 누릅니다.
2. 긴 WAV/M4A/MP3 등의 원본 녹음을 선택합니다.
3. 파형 준비가 끝날 때까지 기다립니다.

확인: 원본 길이와 파형이 있는 편집 창이 열리면 완료입니다.
원본은 읽기만 합니다. 원본 파일에 덮어쓰거나 원본 일부를 삭제하지 않습니다.
긴 파일은 편집기에서 열고, 학습에 들어가는 각 구간은 계속 30초 이하로 만듭니다.

============================================================
[4단계] 구간을 듣고 선택
============================================================
1. 전체 듣기로 원본을 확인합니다.
2. 파형 위에서 마우스로 드래그해 필요한 구간을 선택합니다.
3. 시작·끝 초 값을 입력해서 경계를 더 세밀하게 조정할 수도 있습니다.
4. 선택 구간 듣기로 잘린 앞뒤 발음을 확인합니다.

문장이나 숨이 끊기는 지점에서 나누는 것이 좋습니다.
단어 한가운데가 잘렸다면 경계를 조금 옮겨 다시 들어보세요.
30초가 넘는 선택은 저장할 수 없으므로 두 구간 이상으로 나눕니다.

============================================================
[5단계] 여러 구간을 저장 목록에 담기
============================================================
1. 선택이 맞으면 '구간 담기'를 누릅니다.
2. 다음 구간을 선택하고 같은 방식으로 목록에 담습니다.
3. 저장 목록에서 잘못 담은 구간은 제거하거나 수정합니다.

목록의 구간을 제거해도 원본 음성은 삭제되지 않습니다.
이 단계에서 담은 구간만 별도 파일로 저장합니다.
모든 무음을 지우거나 문장을 자동으로 알아서 나누는 기능은 아닙니다.

확인: 저장 목록의 각 구간이 30초 이하이고 실제 발화가 알맞게 담겼는지 봅니다.

============================================================
[6단계] 세션과 저장 폴더 확인
============================================================
원본 세션:
같은 원본에서 자른 모든 구간은 하나의 세션으로 묶습니다.
기본값은 원본 음성으로 만든 source-... 이름입니다.
같은 원본을 다시 열면 같은 기본 세션을 사용합니다.
필요하면 저장 전에 알아보기 쉬운 이름으로 바꾸되 같은 원본은 같은 이름을 유지하세요.
필터만 달리한 같은 원본도 같은 세션으로 묶습니다.

언어:
한국어 중심은 ko, 영어 중심은 en으로 확인합니다.

저장 폴더:
원본과 구간 파일을 구분해서 보관할 폴더를 선택합니다.
기본 위치는 원본 옆의 원본이름_cuts 폴더입니다.
기존 파일과 이름이 겹치면 번호를 늘려 새 파일로 저장합니다.

============================================================
[7단계] 파일 저장 후 현재 목록에 추가
============================================================
1. '저장 후 현재 목록에 추가'가 체크되어 있는지 확인합니다.
2. 구간 파일 저장 버튼을 누릅니다.
3. 저장과 목록 추가가 끝날 때까지 기다립니다.

체크되어 있으면:
원본이름_001.wav, 원본이름_002.wav처럼 잘린 파일을 저장하고
현재 프로젝트의 audio에도 가져와 목록에 추가합니다.
따로 파일 선택창을 열어 다시 추가할 필요가 없습니다.

체크를 끄면:
잘린 WAV 파일만 저장합니다. 나중에 일반 파일 추가로 가져올 수 있습니다.
이때도 같은 원본의 구간은 같은 세션으로 지정하세요.

확인: 현재 목록에 잘린 녹음이 추가되면 편집 작업이 끝났습니다.
이미 등록된 같은 음성은 중복 추가하지 않으며 기존 정답·검수 상태는 유지합니다.

============================================================
[8단계] 구간별 정답 입력과 저장
============================================================
새 구간은 빈 정답·미검수 상태로 들어옵니다.
1. 각 구간의 '다시 듣기'를 누릅니다.
2. 해당 구간에서 실제로 말한 내용만 정답칸에 적습니다.
3. 검수 완료를 체크합니다.
4. '초안·검수 자료 일괄 저장'을 누릅니다.

원본 전체 대본을 각 짧은 구간의 정답에 그대로 붙이지 마세요.
각 구간의 음성과 그 구간의 정답이 일치해야 합니다.
편집하거나 파일을 저장한 것만으로 AI가 학습되지는 않습니다.

============================================================
[보관] 원본과 세션 유지
============================================================
원본 녹음, 따로 저장한 구간 파일, 프로젝트 자료 폴더를 보관하세요.
파형을 위한 임시 파일은 편집기를 닫을 때 정리합니다.
잘린 파일의 재생은 프로젝트가 보관한 WAV로 할 수 있습니다.

같은 원본의 구간들을 학습용과 검증·평가용으로 나눠 넣지 않습니다.
기존 학습에 쓴 원본을 새로 잘랐다고 독립적인 검증·평가 자료가 되지는 않습니다.
검증 자료는 기존 검증 폴더에서 준비하고 '검증 폴더 연결' 절차를 따릅니다.
