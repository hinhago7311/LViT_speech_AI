LViT 음성 편집기 사용법
최종 수정: 2026-11-22

긴 원본에서 필요한 구간을 골라 각각의 WAV 파일로 저장하는 편집기입니다.
이번 버전은 파일만 저장합니다. 학습 목록에 자동 등록하지 않습니다.
편집기에서 파일을 저장한 뒤 일반 파일 추가 버튼으로 직접 등록합니다.

============================================================
[1단계] 기존 앱에 덮어쓰기
============================================================
1. 현재 목록의 '초안·검수 자료 일괄 저장'을 누릅니다.
2. 학습 중이면 중지하고 종료될 때까지 기다립니다.
3. 앱과 함께 열린 실행창을 닫습니다.
4. 수정본 ZIP 안의 파일을 start_learning.bat이 있는 기존 앱 폴더에 복사합니다.
5. 같은 이름의 파일은 덮어쓰고 기존 start_learning.bat을 실행합니다.

기존 data, .venv, 학습 모델, 검증 연결은 유지합니다.
추가 패키지 설치나 Python 재설치는 필요 없습니다.

============================================================
[2단계] 긴 원본 녹음 열기
============================================================
1. 앱 상단의 '음성 편집기'를 누릅니다.
2. 편집할 WAV/M4A/MP3 등의 원본 녹음을 선택합니다.
3. 파형 준비가 끝날 때까지 기다립니다.

확인: 원본 이름·길이와 파형이 보이면 다음 단계로 갑니다.
30초가 넘는 원본도 편집기에서 열 수 있습니다.
원본은 읽기만 합니다. 편집 목록에서 구간을 바꿔도 원본에 덮어쓰지 않습니다.

============================================================
[3단계] 구간을 듣고 선택
============================================================
1. '전체 듣기'로 원본을 확인합니다.
2. 파형 위를 마우스로 드래그해 필요한 구간을 선택합니다.
3. 시작·끝 초 값을 입력해서 경계를 세밀하게 조정할 수도 있습니다.
4. '선택 구간 듣기'로 문장 앞뒤가 잘리지 않았는지 확인합니다.

저장할 구간 하나는 30초 이하여야 합니다.
길다면 문장 사이에서 둘 이상의 구간으로 나누세요.
단어 중간이 잘렸다면 시작·끝을 조금 옮겨 다시 듣습니다.

============================================================
[4단계] 파일명과 저장 여부를 정해 구간 담기
============================================================
1. 선택한 구간에 알아보기 쉬운 파일명을 입력합니다.
   예: 인사_01
   WAV 확장자는 자동으로 처리하므로 이름만 입력해도 됩니다.
2. 구간의 처리를 '저장' 또는 '제외'로 선택합니다.
3. '구간 담기'를 누릅니다.
4. 다음 구간도 선택하고 같은 순서로 목록에 담습니다.

저장:
  최종 저장할 때 해당 행의 구간을 WAV 파일 하나로 만듭니다.
제외:
  행은 목록에 남겨두고, 최종 저장에서 파일을 만들지 않습니다.
  필요하면 나중에 다시 '저장'으로 바꿀 수 있습니다.

파일명은 같은 녹음 회차를 뜻하는 '세션 이름'과 다릅니다.
예를 들어 인사_01.wav와 안내_02.wav도 같은 원본에서 잘랐다면 같은 세션입니다.

============================================================
[5단계] 담아둔 구간 수정 또는 삭제
============================================================
구간을 수정하려면:
1. 목록에서 수정할 행 하나를 선택합니다.
2. 파일명·시작 초·끝 초·처리(저장/제외)를 원하는 값으로 바꿉니다.
3. 필요한 경우 '선택 구간 듣기'로 확인합니다.
4. 반드시 '선택 구간 수정'을 눌러 목록에 반영합니다.

입력칸만 바꾸고 수정 버튼을 누르지 않으면 목록의 기존 값이 남을 수 있습니다.
수정 후 목록의 파일명·경계·처리가 원하는 값인지 확인하세요.

잘못 담은 구간을 목록에서 빼려면:
1. 해당 행을 선택합니다.
2. '선택 구간 삭제'를 누릅니다.

이 삭제는 아직 저장할 편집 목록에서 행을 빼는 동작입니다.
원본 녹음이나 이미 저장해 둔 WAV 파일을 삭제하지 않습니다.
다시 필요해지면 원본에서 같은 구간을 선택해 '구간 담기'로 넣을 수 있습니다.

============================================================
[6단계] 저장 폴더 확인 후 파일 저장
============================================================
1. 저장 폴더를 확인합니다.
   기본 위치는 원본 옆의 원본이름_cuts 폴더입니다.
2. '저장'으로 표시한 행만 최종 저장할 구간인지 확인합니다.
3. 저장할 각 구간이 30초 이하인지 확인합니다.
4. '저장할 구간 파일 저장'을 누릅니다.
5. 저장이 끝나면 안내된 폴더에서 WAV 파일들을 확인합니다.

파일은 지정한 이름으로 각각 저장됩니다.
기존 파일과 이름이 겹치면 번호를 붙인 새 이름으로 저장하고 기존 파일은 보존합니다.
'제외'로 표시한 행은 저장하지 않습니다.

여기까지는 WAV 파일만 만든 상태입니다.
학습 자료의 정답·세션·언어·검수 기록은 아직 등록하지 않았습니다.
편집기에 학습 자동 등록 체크나 세션·언어 입력은 없습니다.

============================================================
[7단계] 저장한 WAV를 학습 앱에 직접 등록
============================================================
1. 학습 앱에서 등록할 자료 폴더를 확인합니다.
   학습용이면 원래 data\my-voice를 사용합니다.
   검증·평가용이면 별도의 해당 자료 폴더를 엽니다.
2. 상단 '새 파일의 녹음 세션'을 먼저 입력합니다.
   같은 원본에서 자른 모든 파일은 같은 세션 이름을 사용합니다.
3. 상단의 '새 파일 언어'를 실제 발화 언어로 선택합니다.
4. '+ 음성 파일 여러 개 추가'를 누릅니다.
5. 원본이름_cuts 폴더에서 등록할 WAV 파일들을 선택합니다.

원본에서 자른 구간마다 파일명이 달라도 같은 원본은 같은 세션으로 묶습니다.
같은 원본을 다시 편집하거나 필터만 다르게 적용한 버전도 같은 세션으로 유지하세요.
기존 학습에 사용한 원본을 다시 잘라 검증·평가용으로 넣지 않습니다.

============================================================
[8단계] 구간별 정답과 검수 저장
============================================================
1. 각 항목의 '다시 듣기'를 누릅니다.
2. 그 구간에서 실제로 말한 내용만 정답칸에 적습니다.
3. 녹음 세션·언어·정답을 확인하고 검수 완료를 체크합니다.
4. '초안·검수 자료 일괄 저장'을 누릅니다.

원본 전체 대본을 모든 구간의 정답에 붙이지 마세요.
각 짧은 파일과 그 파일의 정답 문장이 맞아야 합니다.
편집·파일 저장·자료 등록만으로 AI가 학습되지는 않습니다.
화면 정리에는 '현재 목록 숨기기'를 사용하고 자료는 유지합니다.

새 검증 자료는 별도 검증 폴더에서 검수·저장한 뒤 원래 학습 폴더로 돌아와
'검증 폴더 연결'을 사용합니다. 자세한 순서는 VALIDATION_GUIDE_KO.txt를 참고하세요.
독립 평가용 자료를 등록했다면 학습 점검·학습 시작은 누르지 않습니다.

============================================================
[보관] 원본과 저장 파일
============================================================
원본 녹음, 원본이름_cuts의 WAV, 정답을 등록한 자료 폴더를 함께 보관하세요.
파형을 위한 임시 파일은 편집기를 닫을 때 정리합니다.
임시 파일과 사용자가 저장한 구간 WAV는 다른 파일입니다.
구간을 제외하거나 편집 목록에서 삭제해도 원본·기존 WAV는 보존됩니다.
