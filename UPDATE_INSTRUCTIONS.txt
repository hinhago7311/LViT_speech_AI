LViT 음성 학습 스튜디오 덮어쓰기 업데이트
2026-11-22

1. 현재 목록의 '초안·검수 자료 일괄 저장'을 누릅니다.
2. 학습 중이라면 중지하고 종료될 때까지 기다립니다.
3. 앱과 함께 열린 실행창을 닫습니다.
4. ZIP 안의 파일을 start_learning.bat이 있는 기존 앱 폴더에 복사합니다.
5. 같은 이름의 파일은 덮어쓰기를 선택합니다.
6. 기존 start_learning.bat을 실행합니다.

이 ZIP에는 data, .venv, 모델 가중치, 개인 녹음·정답·보고서가 없습니다.
기존 앱 폴더를 삭제하거나 새로 설치하지 않습니다.
설치 환경과 학습 자료를 유지하며 추가 패키지 설치도 필요 없습니다.

이번 수정: 음성 편집기의 구간별 파일명과 저장·제외
- 원본을 열고 파형 드래그 또는 시작·끝 초 입력으로 구간을 고릅니다.
- 구간마다 파일명을 입력합니다. WAV 확장자는 자동으로 처리합니다.
- 각 구간을 '저장' 또는 '제외'로 정할 수 있습니다.
- 목록의 행을 고른 뒤 파일명·경계·처리를 바꾸고 '선택 구간 수정'을 누릅니다.
- '선택 구간 삭제'는 저장 전 편집 목록에서만 뺍니다. 원본·기존 파일은 보존합니다.
- '저장할 구간 파일 저장'을 누르면 저장 대상으로 정한 구간만 각각 WAV로 만듭니다.
- 저장하는 각 파일은 30초 이하이며, 기존 동명 파일은 번호를 붙여 보존합니다.
- 기본 저장 위치는 원본 옆의 원본이름_cuts 폴더입니다.

편집기는 파일만 저장합니다. 학습 목록 자동 등록은 제거했습니다.
저장 후 학습 앱의 '+ 음성 파일 여러 개 추가'로 필요한 WAV를 직접 등록하세요.
세션과 언어는 학습 앱에서 등록 전에 지정하고, 구간별 정답을 입력·검수·저장합니다.
같은 원본에서 자른 파일은 파일명이 달라도 같은 세션으로 유지합니다.
친절한 단계별 설명은 AUDIO_EDITOR_GUIDE_KO.txt를 열어주세요.

기존 기능: 새 검증 녹음 연결
- 학습 실행 영역의 '검증 폴더 연결'을 사용합니다.
- 별도 폴더에서 검수한 새 녹음을 기존 검증에 더합니다.
- 기존 학습·평가 배정과 모델은 유지합니다.
- 검증 연결은 다음 실행과 다음 학습에도 이어집니다.
- 모델 이력에 기록된 학습·평가 자료, 중복 음성·세션의 연결을 거부합니다.

자세한 버튼 순서와 결과 읽는 법은 VALIDATION_GUIDE_KO.txt를 열어주세요.
이미 validation_sample에서 정답·검수·저장을 마쳤다면 안내의 3단계부터 진행합니다.

기존 화면 숨김, 언어 선택·정정, 검수 상태 보존 기능도 유지합니다.
검증 자료가 달라진 전후 CER은 바로 비교하지 말고 같은 확장 검증 기준으로 비교하세요.
기존 LViT 자막 앱이나 보류 중인 표정·단축키 기능은 이 업데이트에서 변경하지 않습니다.
