1. 따로 빼둔 녹음으로 평가하기
사용할 명령어: 1_평가실행_명령어.txt

한 단계가 끝나면 화면을 확인한 뒤 다음 단계로 넘어가세요.
평가용 정답·검수 저장까지 이미 마쳤다면 [4단계]부터 시작합니다.

============================================================
[1단계] 앱에서 평가 자료 폴더 열기
============================================================
1. start_learning.bat을 실행해 앱을 엽니다.
2. 기존 학습 자료가 보이면 '초안·검수 자료 일괄 저장'을 누릅니다.
3. 앱 맨 위 오른쪽의 '다른 폴더 열기'를 누릅니다.
4. 바탕화면 → sample → test_sample으로 이동합니다.
5. '폴더 선택' 또는 '확인'을 누릅니다.

확인: 앱 위쪽 자료 폴더가 test_sample로 바뀌면 완료입니다.
처음 여는 평가 폴더라면 목록이 비어 있어도 정상입니다.

창 제목이 '음성 파일 여러 개 선택'이라면 녹음 추가 창입니다.
취소한 뒤 앱 맨 위의 '다른 폴더 열기'를 눌러주세요.

============================================================
[2단계] 세션과 언어를 정한 뒤 녹음 추가
============================================================
1. 상단 '새 파일의 녹음 세션'을 test001로 입력합니다.
2. 한국어 중심 녹음이면 언어를 ko로 고릅니다. 영어 중심이면 en입니다.
3. '음성 파일 여러 개 추가'를 누릅니다.
4. 시험용으로 빼둔 녹음 파일을 선택하고 '열기'를 누릅니다.

확인: 녹음이 앱 목록에 나타나면 완료입니다.
세션과 언어는 파일 추가 전에 정합니다.
test001은 예시입니다. 기존 학습·검증 세션과 겹치지 않게 정하세요.
같은 원본을 나누거나 필터만 달리한 녹음은 같은 세션으로 묶습니다.
이름만 바꾼 같은 원본은 독립 평가 자료가 되지 않습니다.
평가만 할 때는 세션 1개, 녹음 1개부터 가능합니다. 파일당 30초 이하입니다.

============================================================
[3단계] 정답 입력 → 검수 → 저장
============================================================
1. '다시 듣기'로 녹음을 듣습니다.
2. 오른쪽 정답칸에 실제로 말씀하신 내용을 그대로 입력합니다.
3. 해당 항목의 '검수 완료'를 체크합니다.
4. '초안·검수 자료 일괄 저장'을 누릅니다.

확인: 평가 폴더에 manifest.jsonl이 생기면 평가 목록 저장이 완료됐습니다.
여러 녹음이면 각각의 정답을 입력하고 검수합니다.
대본과 실제 발화가 다르면 실제 발화를 기준으로 적습니다.
WAV/M4A만 복사해 둔 상태는 정답 등록까지 끝난 상태가 아닙니다.
언어 정정은 상단 언어 선택 → 보이는 항목 언어 적용 → 재검수 → 저장입니다.
이 평가 폴더에서는 '학습 점검'과 '학습 시작'을 누르지 않습니다.

============================================================
[4단계] 검은 CMD 창 열기
============================================================
1. 탐색기에서 start_learning.bat과 app.py가 보이는 앱 폴더를 엽니다.
2. Ctrl+L로 주소창을 선택합니다.
3. cmd를 입력하고 Enter를 누릅니다.

확인: 검은 CMD 창의 현재 위치가 앱 폴더이면 완료입니다.
평가용 test_sample 폴더와 명령을 실행할 앱 폴더는 용도가 다릅니다.

============================================================
[5단계] 평가 명령 복사하기
============================================================
1. 1_평가실행_명령어.txt를 메모장으로 엽니다.
2. Ctrl+A → Ctrl+C로 그 파일 전체를 복사합니다.
3. CMD에 붙여넣고 Enter를 누릅니다.

확인: 학습 모델의 best 폴더를 고르는 창이 뜨면 완료입니다.

============================================================
[6단계] 두 선택창에서 무엇을 고르나요?
============================================================
첫 번째 창: 평가할 학습 모델의 best 폴더
1. 평가할 본학습 회차의 폴더로 이동합니다.
   보통 앱 폴더\data\my-voice\runs\학습회차폴더\best입니다.
2. 주소 끝이 best이면 '폴더 선택' 또는 '확인'을 누릅니다.
   best 안의 개별 파일을 고르는 단계는 아닙니다.

기본 학습 자료의 연결 모델이 있으면 그 위치를 먼저 엽니다.
점검용 실행도 모델을 만들 수 있으므로 본학습 완료 로그의 경로를 확인하세요.
과거 회차를 다시 평가하려면 그 과거 회차의 best를 고릅니다.

두 번째 창: 평가 폴더의 manifest.jsonl
1. 바탕화면 → sample → test_sample로 이동합니다.
2. manifest.jsonl을 고릅니다. 확장자가 숨겨져 있으면 manifest로 보일 수 있습니다.
3. '열기'를 누릅니다.

확인: 검은 창에서 평가가 진행되면 파일 선택이 끝난 것입니다.
직접 만든 유효한 JSONL 목록이라면 파일 이름이 달라도 선택할 수 있습니다.
바탕화면이 OneDrive 등 다른 위치에 있으면 직접 찾아가세요.

============================================================
[7단계] 완료 확인과 CER 해석
============================================================
원본 모델과 선택한 학습 모델을 순서대로 평가합니다.
끝날 때까지 CMD를 닫지 말고 기다려주세요. 추가 학습하는 과정은 아닙니다.

완료 시 확인할 두 줄:
CER: 앞의 수치 → 뒤의 수치
보고서: reports\new-test-여러문자.json

- 앞: 원본 Whisper small의 문자 오류율
- 뒤: 이번에 선택한 학습 모델의 문자 오류율
- 뒤가 낮음: 이번 평가에서 오류율 감소
- 같음: 표시된 오류율 동일. 문장이 같은지는 2번 안내에서 확인
- 뒤가 높음: 이번 평가에서 오류율 증가

CER은 낮을수록 좋습니다. 공백·문장부호·대소문자 차이는 제외합니다.
표시는 소수 둘째 자리 반올림이므로 아주 작은 차이는 가려질 수 있습니다.
정밀한 회차 비교는 3번 안내를 사용하세요.
앞의 값은 직전 학습 회차 점수가 아닙니다. 회차끼리 비교하려면 3번 안내를 보세요.
평가 녹음이 다르면 예전 CER과 이번 CER을 직접 전후 비교하지 않습니다.

확인: CER과 보고서 경로가 나오면 평가가 끝났습니다.
새 JSON 이름을 적어두고 '2_결과보기_안내.txt'를 여세요.

============================================================
[평가 후] 원래 학습 자료 폴더로 돌아가기
============================================================
앱의 '다른 폴더 열기' → 앱 폴더 → data → my-voice를 선택합니다.
다른 학습 폴더를 쓰셨다면 그 폴더를 선택하세요.
원래 학습 목록이 보이면 완료입니다. test001은 별도 평가 폴더에 계속 남겨둡니다.
