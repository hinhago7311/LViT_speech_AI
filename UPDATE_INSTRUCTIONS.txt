LViT 음성 학습 스튜디오 업데이트 안내
2026-11-19

이 ZIP은 기존 설치에 덮어쓰는 수정본입니다.
자료 폴더, 모델, 설치 환경을 다시 만들지 않습니다.

적용 순서
1. 학습 중이라면 학습 중지 후 종료될 때까지 기다립니다.
2. 학습 앱과 함께 열린 실행창을 닫습니다.
3. ZIP 안의 파일들을 start_learning.bat이 있는 기존 폴더에 복사합니다.
4. 같은 파일을 바꿀지 물으면 덮어쓰기를 선택합니다.
5. 기존 start_learning.bat으로 다시 실행합니다.

업데이트 ZIP에는 data, .venv, 모델 가중치가 포함되어 있지 않습니다.
기존 data와 .venv는 그대로 유지하세요. 패키지 재설치는 필요 없습니다.
새 폴더에서 실행하지 말고 기존 앱 폴더의 파일만 교체합니다.

이번 수정
- 항목별 언어 선택기는 읽기 전용 표시로 바뀌었습니다.
- 상단의 새 파일 언어를 고른 뒤 새 녹음을 추가합니다.
- 마우스 휠로 상단 언어가 바뀌지 않습니다.
- 기존 자료는 보이는 항목 언어 적용 버튼을 누를 때만 언어가 바뀝니다.
- 바뀐 항목은 다시 검수 완료한 뒤 저장합니다.
- 기존 검증·평가 음성과 세션을 유지하면서 검수된 정답·언어 정정을 반영합니다.
- 정정 내역은 새 prepared 폴더의 label_corrections.json에 남습니다.
- 이전 분할 폴더와 모델은 바꾸지 않습니다.

이미 en을 ko로 바로잡은 경우
1. 전체 다시 보기로 해당 항목을 확인합니다.
2. 그 항목이 ko인지 확인하고 검수 완료를 다시 체크합니다.
3. 초안·검수 자료 일괄 저장을 누릅니다.
4. 기존 분할·이전 모델 연결을 유지하고 학습 점검 또는 학습을 실행합니다.

누락된 이전 음성이나 변경된 세션 이름은 계속 검사합니다.
그런 오류가 남으면 기존 분할을 지우거나 잘못된 언어로 되돌리지 말고
오류에 표시된 항목의 음성·세션·검수 상태를 확인하세요.

평가 정답·언어가 바뀌면 원본 모델과 학습 모델을 정정된 같은 자료로 다시 평가합니다.
