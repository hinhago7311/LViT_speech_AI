LViT 평가 · 결과 보기 · 회차 비교 · 학습 기록
Windows 메모장용 / 한 단계씩 따라가는 안내

============================================================
먼저 이 파일만 읽어주세요
============================================================
한 번에 전부 진행하지 않으셔도 됩니다.
필요한 번호의 안내 파일 하나를 열고, 한 단계씩 끝낸 뒤 다음으로 넘어가세요.
각 안내 파일에 누를 버튼, 고를 파일, 결과 해석, 완료 기준을 함께 적었습니다.

1. 처음 시험용 녹음을 평가하려고 합니다.
   → 1_평가실행_안내.txt
2. 평가가 끝났고 CER 또는 JSON 보고서가 나왔습니다.
   → 2_결과보기_안내.txt
3. 이전 학습 회차와 이번 회차가 얼마나 달라졌는지 보고 싶습니다.
   → 3_회차비교_안내.txt
4. 학습이 진행됐는지, 왜 best가 0 / 0인지 알고 싶습니다.
   → 4_학습기록보기_안내.txt

============================================================
명령어를 복사하는 방법
============================================================
각 안내 파일과 같은 번호의 '명령어.txt'가 짝입니다.
예: 2_결과보기_안내.txt + 2_결과보기_명령어.txt

1. 안내 파일에서 현재 단계를 읽습니다.
2. 같은 번호의 명령어 파일을 메모장으로 엽니다.
3. Ctrl+A → Ctrl+C로 그 파일 전체를 복사합니다.
4. 앱 폴더에서 연 CMD에 붙여넣고 Enter를 누릅니다.

명령어 파일에는 실행할 한 줄만 들어 있습니다.
안내 파일 전체를 CMD에 붙여넣지 마세요.
메모장에서 여러 줄로 보이더라도 자동 줄바꿈일 수 있습니다.

CMD 여는 법:
탐색기에서 start_learning.bat과 app.py가 보이는 앱 폴더를 엽니다.
Ctrl+L → cmd 입력 → Enter를 누르면 검은 창이 열립니다.
명령을 실행하는 위치는 이 앱 폴더입니다.

============================================================
폴더와 이름 구분하기
============================================================
평가 자료 폴더 예시: 바탕화면\sample\test_sample
평가 세션 이름 예시: test001
원래 학습 자료 폴더: 앱 폴더\data\my-voice

녹음 파일 이름, 세션 이름, 폴더 이름은 서로 다릅니다.
- 녹음 파일: 실제 소리가 들어 있는 WAV/M4A 등의 파일
- 세션: 같은 녹음 회차나 같은 원본에서 나온 자료를 묶는 이름
- manifest.jsonl: 정답·언어·검수를 저장한 평가 목록

바탕화면을 OneDrive나 다른 드라이브로 옮겼다면 선택창에서 직접 찾아가세요.
평가 녹음은 학습에 넣지 않고, 같은 녹음과 정답을 다음 회차에도 유지합니다.

============================================================
기존 메모장에 덮어쓰는 방법
============================================================
기존 안내 메모장을 닫고 새 ZIP을 기존 설명서가 있는 폴더에 풀어주세요.
같은 이름의 파일을 바꿀지 물으면 '대상 폴더의 파일 덮어쓰기'를 선택합니다.
기존 'LViT_평가_결과_비교_안내.txt'와 명령어 1~3의 파일명은 유지했습니다.
번호별 안내 4개와 학습 기록 명령어 4번은 같은 폴더에 추가됩니다.

설명서와 명령어 TXT만 들어 있으므로 앱 재설치가 필요 없습니다.
학습 자료·모델·가상환경·기존 평가 보고서를 덮어쓰지 않습니다.

============================================================
보관할 것
============================================================
- 평가 폴더 전체: 음성, 정답, 언어, 세션, 검수 목록
- reports의 평가 JSON: 점수, 정답, 인식 문장, 음성 경로
- data\my-voice\runs의 학습 회차 폴더: best와 history.json
- result-/round-compare-/training-history-로 시작하는 TXT: 읽기용 요약

평가 JSON에 음성 파일 자체가 들어 있는 것은 아닙니다.
TXT 요약만 남기지 말고 원래 평가 JSON과 음성도 함께 보관하세요.
