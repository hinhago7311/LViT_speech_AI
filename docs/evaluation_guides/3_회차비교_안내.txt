3. 이전 학습 회차와 이번 학습 회차 비교하기
사용할 명령어: 3_회차비교_명령어.txt

============================================================
[준비] 두 개의 평가 JSON 준비
============================================================
이전 모델을 평가한 JSON 1개와 이번 모델을 평가한 JSON 1개가 필요합니다.
두 보고서는 같은 음성·정답·언어·세션·점수 계산 방식으로 만들어야 합니다.

1. 1번 평가 명령에서 이전 회차의 best를 골라 평가합니다.
2. 같은 명령을 다시 실행해 이번 회차의 best를 고릅니다.
3. 두 번 모두 동일한 평가 폴더의 manifest.jsonl을 고릅니다.
4. 어느 JSON이 이전 모델이고 어느 JSON이 이번 모델인지 적어둡니다.

이전 보고서가 같은 평가 자료로 이미 만들어져 있으면 그대로 사용할 수 있습니다.
과거 보고서가 없으면 과거 best를 다시 평가합니다. 그 best 폴더를 보관해야 가능합니다.
정답·언어를 정정했다면 두 모델 모두 같은 정정 자료로 다시 평가합니다.
설정 정정 효과와 모델 학습 효과를 섞지 않습니다.

============================================================
[1단계] 비교 명령 실행
============================================================
1. 앱 폴더에서 CMD를 엽니다. 이미 열어둔 창이면 그대로 사용합니다.
   새로 열 때는 start_learning.bat이 보이는 폴더에서 Ctrl+L → cmd → Enter입니다.
2. 3_회차비교_명령어.txt를 메모장으로 엽니다.
3. Ctrl+A → Ctrl+C로 전체 복사합니다.
4. CMD에 붙여넣고 Enter를 누릅니다.

확인: 첫 번째 보고서를 고르는 창이 뜨면 완료입니다.

============================================================
[2단계] 두 보고서를 순서대로 선택
============================================================
첫 번째 창: 이전 회차의 평가 JSON을 고르고 '열기'를 누릅니다.
두 번째 창: 이번 회차의 평가 JSON을 고르고 '열기'를 누릅니다.

두 창 모두 앱 폴더\reports 안의 평가 JSON을 고릅니다.
서로 다른 파일 두 개를 고르세요. 순서가 바뀌면 개선/악화 방향도 바뀝니다.

확인: 메모장이 열리고 '학습 회차 비교'가 보이면 완료입니다.

============================================================
[해석] 메모장에서 무엇을 보나요?
============================================================
이전 학습 모델 CER / 이번 학습 모델 CER:
각 보고서의 '학습 모델' 점수끼리 비교합니다.
원본 Whisper small과 학습 모델을 비교하는 1번과는 비교 대상이 다릅니다.

오류율 감소폭(퍼센트포인트):
이전 CER - 이번 CER입니다.
- 양수: 오류율 감소
- 0: 오류율 동일
- 음수: 오류율 증가
가상 예시: 8% → 5%라면 3퍼센트포인트 감소입니다.
비교 판정은 원본 JSON의 숫자로 계산합니다. 표시 숫자는 반올림됩니다.

인식 문장이 달라진 녹음 수:
두 학습 모델의 출력이 달라진 파일 수입니다.
문장부호나 띄어쓰기만 달라도 이 개수에는 포함될 수 있습니다.
CER이 같은데 이 개수가 1 이상이면 2번 결과 보기로 각 문장을 살펴보세요.

이전 모델 / 이번 모델 경로:
원하는 두 학습 회차를 골랐는지 함께 확인합니다.

============================================================
[문제 해결] 비교가 멈췄을 때
============================================================
Evaluation data or scoring differ:
음성 경로·정답·언어·세션·점수 계산 방식 등이 맞지 않는다는 뜻입니다.
같은 평가 자료로 두 모델을 다시 평가하세요.

Base models differ:
원본 모델 정보가 다릅니다. 같은 기반 모델 조건인지 확인하세요.

Choose two different reports:
같은 파일을 두 번 골랐습니다. 이전/이번 두 보고서를 다시 선택하세요.

보고서에는 음성 내용 해시가 없습니다.
이 명령은 기록된 경로 등을 대조하므로 같은 경로의 음성을 교체하지 않고 보관해야 합니다.

============================================================
[완료] 저장되는 파일
============================================================
앱 폴더\reports에 round-compare-여러문자.txt가 새로 저장됩니다.
결과 TXT에도 감소폭과 문장 변화 수를 읽는 요령이 함께 들어 있습니다.
두 원본 JSON과 평가 음성, 두 모델의 best 폴더를 함께 보관하세요.
