4. 학습 진행과 best 선택 이유 확인하기
사용할 명령어: 4_학습기록보기_명령어.txt

============================================================
[1단계] 학습 기록 보기 명령 실행
============================================================
1. 앱 폴더에서 CMD를 엽니다. 이미 열어둔 창이면 그대로 사용합니다.
   새로 열 때는 start_learning.bat이 보이는 폴더에서 Ctrl+L → cmd → Enter입니다.
2. 4_학습기록보기_명령어.txt를 메모장으로 엽니다.
3. Ctrl+A → Ctrl+C로 전체 복사합니다.
4. CMD에 붙여넣고 Enter를 누릅니다.

확인: 모델의 best 폴더를 고르는 창이 뜨면 완료입니다.

============================================================
[2단계] 확인할 회차의 best 선택
============================================================
1. 확인할 본학습 회차의 best 폴더로 이동합니다.
   보통 앱 폴더\data\my-voice\runs\학습회차폴더\best입니다.
2. 주소 끝이 best이면 '폴더 선택' 또는 '확인'을 누릅니다.

2번 결과 메모장의 '모델:' 경로와 같은 best를 고르면
지금 평가한 모델의 학습 기록을 확인할 수 있습니다.
단순히 가장 최근 폴더를 고르면 점검용 실행을 열 수도 있습니다.

확인: 메모장이 열리고 '학습 기록' 표가 보이면 완료입니다.
아래에는 원본 history.json 내용도 함께 표시합니다.

============================================================
[해석 1] 먼저 두 숫자를 구분하세요
============================================================
기록된 마지막 epoch / step:
history.json에서 확인되는 이번 회차의 진행 지점입니다.
학습이 얼마나 진행됐는지는 이 값을 봅니다.

선택된 best epoch / step:
training_info.json에 기록된 최종 선택 시점입니다.
학습은 여러 단계 진행됐어도 이 값은 0 / 0일 수 있습니다.

history.json 위치: 학습회차폴더\history.json
training_info.json 위치: 학습회차폴더\best\training_info.json

============================================================
[해석 2] 표의 각 항목 읽기
============================================================
epoch:
학습 자료를 반복한 회차입니다. 0은 이번 실행의 학습 시작 전 상태입니다.

step:
이번 실행에서 기록한 누적 모델 업데이트 단계입니다. 파일 수나 초 단위 시간이 아닙니다.
이전 어댑터에서 이어 학습해도 이번 실행의 epoch와 step은 다시 시작합니다.

학습 loss:
학습 자료에서 계산한 평균 손실입니다. 0회차에는 없으므로 '-'로 표시합니다.
낮아지는 추세는 확인할 수 있지만 자막 CER 개선의 증거로 대신 쓰지는 않습니다.

검증 CER:
모델 선택용 검증 녹음의 문자 오류율입니다. 낮을수록 좋습니다.
2번 결과의 시험용 CER과는 자료가 다릅니다. 서로 같은 점수로 비교하지 않습니다.

검증 오류 수 / 정답 글자 수:
검증 CER 계산에 사용한 문자 오류 수와 정답 글자 수입니다.
정답 글자가 적고 오류가 하나뿐이면 점수 변화의 여지가 작을 수 있습니다.

============================================================
[해석 3] 왜 best가 0 / 0인가요?
============================================================
이 앱은 학습 시작 상태를 먼저 best 후보로 저장합니다.
그 뒤 검증 CER이 엄격히 더 낮아질 때만 best를 교체합니다.
같거나 높으면 기존 best를 유지합니다. loss 감소만으로는 바꾸지 않습니다.

- 마지막 진행 step이 0보다 크면 그 지점까지 학습 진행 기록이 있습니다.
- best가 0 / 0이면 이번 실행 시작 상태가 최종 모델로 남았습니다.
- 이 경우 best에는 이번 실행 중 업데이트한 변화가 반영되지 않습니다.
- 이어 학습이었다면 시작 상태는 이전 어댑터일 수 있습니다.

학습 완료와 인식 개선은 따로 확인해야 합니다.
best가 나중 epoch에서 선택돼도 시험용 성능은 1~3번 평가로 확인합니다.

가상 예시로 읽어보기:
시작: epoch 0 / step 0 / 검증 CER 2.5%
1회차: step 4 / loss 1.2 / 검증 CER 2.5%
2회차: step 8 / loss 1.1 / 검증 CER 2.5%
3회차: step 12 / loss 1.0 / 검증 CER 2.5%
선택된 best: epoch 0 / step 0

이 예시는 학습이 12단계 진행됐고 loss도 줄었지만,
검증 CER은 같아서 시작 모델이 best로 유지된 경우입니다.

============================================================
[해석 4] 기록이 없거나 점수가 그대로일 때
============================================================
history.json이 없다고 나오는 경우:
선택한 best의 한 단계 위에 history.json이 있는지 확인합니다.
첫 epoch 검증이 끝난 뒤부터 기록하므로 중단된 실행에는 없을 수도 있습니다.
앱의 완료/중지/오류 로그도 확인하세요. 파일이 없다는 사실만으로 단정하지 않습니다.

마지막 행이 있다고 전체 학습이 정상 완료됐다고 단정하지 않습니다.
중간 기록 이후 중단됐을 수도 있으므로 완료 로그와 함께 봅니다.

검증 CER이 계속 같은 경우:
동점이면 시작 모델 또는 이전 best가 남는 것이 현재 선택 규칙입니다.
새로운 내용과 실제 사용 환경의 학습 자료를 모으고 같은 평가 자료로 확인하세요.
평가용 녹음은 학습 자료에 넣지 않고 유지합니다.

============================================================
[완료] 저장되는 파일과 원래 목록 복귀
============================================================
앱 폴더\reports에 training-history-여러문자.txt가 새로 저장됩니다.
요약, 읽는 법, 원본 history.json 내용을 함께 담습니다.
원래 history.json, training_info.json, 모델 가중치는 수정하지 않습니다.

평가 폴더를 열어두셨다면 앱의 '다른 폴더 열기'를 누르고
기존 앱 폴더 → data → my-voice로 돌아오세요.
다른 학습 폴더를 사용 중이었다면 그 폴더를 선택합니다.
