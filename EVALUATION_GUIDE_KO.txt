LViT 평가 · 결과 보기 · 학습 회차 비교만 모음
Windows 메모장용 / 2026-11-19

이 설명서에는 학습 설치나 녹음 팁을 넣지 않았습니다.
평가용 녹음 준비, 평가 실행, 결과 읽기, 두 학습 회차 비교만 다룹니다.
기존 앱을 그대로 사용합니다. 추가 설치나 앱 재설치는 필요 없습니다.

============================================================
가장 쉬운 사용법
============================================================
1. 처음 평가할 때는 아래 [준비]를 한 번 진행합니다.
2. 앱 폴더에서 CMD를 엽니다.
3. 명령어 전용 TXT를 열고 Ctrl+A → Ctrl+C로 전체 복사합니다.
4. CMD에 붙여넣고 Enter를 누릅니다.

1_평가실행_명령어.txt : 시험용 녹음으로 원본 모델과 선택한 학습 모델 비교
2_결과보기_명령어.txt : 보고서를 읽기 쉬운 TXT로 정리하고 메모장으로 열기
3_회차비교_명령어.txt : 이전 회차와 이번 회차의 학습 모델 성능 비교

명령어 전용 TXT에는 실제 명령 한 줄만 들어 있습니다.
설명서 전체를 복사하지 말고, 해당 명령어 전용 파일을 사용하세요.
메모장에서 자동 줄바꿈으로 보이더라도 실제 명령은 한 줄입니다.

이 설명서 안에도 같은 명령을 전부 넣었습니다.
Ctrl+F로 [명령 1], [명령 2], [명령 3]을 검색하면 바로 찾을 수 있습니다.

============================================================
[준비] 따로 빼둔 시험용 녹음 등록
============================================================
이번에 보관하신 평가 자료:
- 위치: 바탕화면\sample\test_smaple
- 저장 이름: test_sample001

명령 1의 두 번째 선택창은 위 위치를 우선 엽니다.
test_sample001이 하위 폴더라면 그 안을 먼저 엽니다.
바탕화면이 OneDrive 등 다른 위치에 있으면 선택창에서 직접 찾아가세요.
이름의 test_smaple은 알려주신 철자 그대로입니다.

정답·검수 저장까지 이미 마쳤다면 아래 준비를 반복할 필요 없습니다.
1. 현재 학습 목록을 저장합니다.
2. 다른 폴더 열기로 학습 폴더와 분리한 평가 폴더를 엽니다.
   이번 자료는 바탕화면\sample\test_smaple 위치에서 확인합니다.
   test_sample001이 평가 프로젝트 폴더라면 그 폴더를 엽니다.
3. 상단 세션을 eval_new_001처럼 학습·검증 세션과 겹치지 않게 정합니다.
4. 상단 새 파일 언어도 ko 또는 en으로 고릅니다.
5. 음성 파일 여러 개 추가로 시험용 녹음을 가져옵니다. 파일당 30초 이하입니다.
6. 실제로 말한 정답을 입력하고 언어를 확인합니다.
7. 검수 완료 → 초안·검수 자료 일괄 저장을 누릅니다.

한국어 중심 발화는 ko, 영어 중심 발화는 en입니다.
언어를 고칠 때는 상단 선택 → 보이는 항목 언어 적용 → 재검수 → 저장 순서입니다.

이 평가 폴더에서는 학습 점검이나 학습 시작을 누르지 않습니다.
평가만 할 때는 세션 1개, 녹음 1개부터도 가능합니다.
앱에서 저장하면 평가 폴더에 manifest.jsonl이 만들어집니다.
이미 test_sample001.jsonl 같은 유효한 평가 목록을 따로 만들었다면 그 파일을 골라도 됩니다.
WAV나 M4A만 폴더에 복사해 둔 상태라면 정답·검수 등록을 먼저 해야 합니다.

등록 후 앱의 자료 폴더를 원래 학습 자료 폴더로 돌려놓으세요.
같은 평가 폴더의 녹음과 정답을 보관하고, 다음 학습 회차에도 재사용합니다.
평가용 녹음은 학습 자료에 추가하지 않습니다.

============================================================
[CMD] 명령을 입력할 창 여는 방법

[해석] 숫자와 문장을 어떻게 보면 되나요?
============================================================
1. CER은 문자 편집 오류율이며 낮을수록 좋습니다.
   공백·문장부호·대소문자 차이는 제외합니다.
   문장별 점수의 단순 평균이 아니라 전체 오류 수와 전체 정답 글자수로 계산합니다.
   CER을 100에서 뺀 값을 모델의 정확도로 표현하지 마세요.

2. [명령 1]의 앞 값은 원본 Whisper small, 뒤 값은 선택한 학습 모델입니다.
   앞 값이 바로 직전 학습 회차의 점수라는 뜻은 아닙니다.

3. 이전 회차와 이번 회차의 차이는 [명령 3]으로 비교합니다.
   각 JSON의 adapted끼리 비교하는 것입니다.
   오류율 감소폭이 양수면 개선, 0이면 동일, 음수면 증가입니다.

4. 같은 CER이어도 맞고 틀리는 문장이 서로 바뀔 수 있습니다.
   [명령 2]의 정답·원본·학습 문장도 함께 보세요.

5. 학습 완료 메시지만으로 성능 향상을 보장하지는 않습니다.
   선택된 epoch/step이 0이면 이번 실행의 시작 모델이 best로 남은 상태일 수 있습니다.
   이어 학습이었다면 그 시작 모델은 이전 어댑터일 수 있습니다.

6. history.json에 있는 값은 검증 자료의 CER입니다.
   평가 보고서에 있는 값은 시험용 자료의 CER입니다. 서로 같은 점수로 취급하지 않습니다.

7. 정답이나 언어를 정정했다면 양 모델을 정정된 같은 자료로 다시 평가합니다.
   설정 정정 전후의 숫자 차이를 추가 학습 효과로 해석하지 마세요.
