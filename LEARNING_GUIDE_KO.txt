LViT 음성 학습 · 추가 학습 · 평가 사용 설명서
작성일: 2026-11-19
대상: Windows, Whisper small 학습 스튜디오

이 설명서는 메모장으로 열어두고 순서대로 따라 하시면 됩니다.
이미 학습 점검과 학습이 성공했다면 패키지를 다시 설치할 필요가 없습니다.
현재 쓰는 앱 폴더와 설치 환경을 그대로 사용하세요.

빠른 순서
  세션 지정 → 녹음 추가 → 정답 입력 → 검수 완료 → 일괄 저장
  → 처음에는 1단계 학습 점검 → 학습 시작
  → 따로 보관한 평가용 녹음으로 학습 전후 비교
  → 새 회차 녹음을 기존 목록에 추가하고 이어 학습


[1] 학습 자료를 등록한 뒤

1. 앱 상단의 자료 폴더가 기존 학습 자료 폴더인지 확인합니다.
   기본 위치는 앱 폴더 안의 data\my-voice입니다.
   audio 하위 폴더가 아니라 my-voice를 선택합니다.

2. 각 항목의 정답, 녹음 세션, 언어를 확인합니다.
   - 한국어 중심 발화: ko
   - 영어 중심 발화: en
   - 한글과 영어가 섞인 문장: 주로 말한 언어를 선택합니다.
   - 정답은 번역문이 아니라 실제로 말한 내용을 적습니다.
   - 책이나 대본을 읽다가 단어를 생략·반복했다면 실제 발화대로 적습니다.
   - 녹음 파일 하나는 30초 이하로 준비합니다.
   - M4A 등은 파일 추가 시 학습용 WAV로 자동 변환합니다.

3. 정답을 확인하고 검수 완료를 체크합니다.
   정답·세션·언어를 수정하면 검수 표시가 해제되므로 다시 확인합니다.
   보이는 항목 검수 완료 버튼으로 현재 화면의 항목들을 처리할 수도 있습니다.

4. 초안·검수 자료 일괄 저장을 누릅니다.
   파일 추가나 저장만으로 AI가 학습되지는 않습니다.
   검수 완료한 항목만 실제 학습 입력에 포함됩니다.


[2] 녹음 세션을 나누는 기준

세션은 파일명이 아니라 같은 녹음 회차를 묶는 이름입니다.
같은 회차에서 녹음한 여러 파일은 같은 세션 이름을 사용합니다.
같은 원본을 자른 파일이나 필터만 적용한 변형도 같은 세션으로 묶습니다.

예:
  휴대폰으로 녹음한 첫 회차: phone_001
  NC를 켠 마이크로 새로 녹음한 회차: mic_nc_001
  NC를 끈 마이크로 새로 녹음한 회차: mic_raw_001

처음 학습할 때는 학습·검증·평가 분리를 위해 서로 다른 세션 3개 이상이 필요합니다.
장비가 3종류여야 한다는 뜻은 아닙니다. 같은 장비의 서로 다른 회차도 가능합니다.
이름만 다르게 붙여 같은 원본을 세 세션으로 만들지는 마세요.

상단의 새 파일의 녹음 세션은 이후 추가할 파일에 적용됩니다.
이미 등록한 항목은 각 행 오른쪽의 녹음 세션 칸에서 수정합니다.


[3] 실제 학습 시작하기

1. 장치를 자동으로 선택합니다.
2. 설치 후 처음 실행하는 경우에는 1단계 학습 점검을 누릅니다.
3. 점검이 정상 완료되면 학습 시작을 누릅니다.

1단계 학습 점검도 실제로 아주 짧게 학습하는 기능입니다.
이미 점검을 통과한 환경에서는 추가 학습 때마다 반복할 필요는 없습니다.
첫 실행에는 기본 Whisper small 모델을 다운로드할 수 있습니다.

진행 상황은 앱 아래 로그에 표시됩니다.
학습이 끝날 때까지 앱과 함께 열린 검은 실행창을 유지합니다.
하단에 학습 완료와 best 폴더 경로가 표시되면 종료된 것입니다.
중단이 필요할 때는 학습 중지 버튼을 사용합니다.

학습 완료는 정확도 향상을 보장하는 메시지가 아닙니다.
프로그램은 검증 오류율이 좋아진 결과만 최종 best로 선택합니다.
개선된 결과가 없으면 이번 학습 시작 시점 모델이 best로 남을 수 있습니다.


[4] 화면을 정리할 때와 다음 회차를 추가할 때

화면에서 숨기기 / 현재 목록 숨기기
  화면만 정리합니다. 정답·세션·검수 기록은 유지됩니다.
  숨긴 자료도 함께 저장되며 검수 완료 자료는 학습에 포함됩니다.

전체 다시 보기
  숨긴 자료를 다시 표시합니다.
  자료 폴더를 다시 열어도 저장된 목록 전체가 표시됩니다.

자료에서 제외
  확인 후 실제 등록 목록에서 항목을 뺍니다.
  그 상태로 저장하면 해당 정답·세션 기록도 저장 목록에서 제외됩니다.
  단순한 화면 정리에는 이 버튼을 쓰지 않습니다.

두 번째 이후 녹음을 추가하는 순서:
1. 같은 학습 자료 폴더를 계속 사용합니다.
2. 기존 항목은 유지하고 필요하면 현재 목록 숨기기를 누릅니다.
3. 새 녹음 회차 이름을 phone_002, mic_nc_002 등으로 지정합니다.
4. 새 파일을 추가하고 정답 입력 → 검수 완료 → 일괄 저장합니다.
5. 이전 모델과 기존 분할의 연결을 유지한 채 학습 시작을 누릅니다.

기존 3세션을 빼고 새 세션으로 교체하는 방식이 아닙니다.
기존 자료를 유지하면서 새 자료를 추가합니다.
매번 3세션씩 추가할 필요는 없고 새 회차 하나만 추가해도 됩니다.
기존 분할 연결을 유지하면 새 세션은 학습용으로 추가되고,
기존 검증·평가 세션은 학습에 섞이지 않도록 유지됩니다.

같은 자료 폴더를 다시 열면 이전 학습 연결 정보가 자동으로 복원됩니다.
기존 분할과 이전 모델을 임의로 초기화하거나 지우지 마세요.


[5] 따로 빼둔 시험용 녹음 등록하기

시험용 녹음은 모델이 배우지 않은 자료로 성능을 확인하는 데 사용합니다.
학습용 목록에 섞지 않고 별도 자료 폴더로 관리합니다.

1. 현재 학습 목록을 먼저 저장합니다.
2. 다른 폴더 열기로 별도 평가 폴더를 엽니다.
   예: 문서 폴더 안에 LViT_Eval이라는 폴더를 만들어 사용합니다.
3. 새 파일의 녹음 세션을 eval_new_001처럼 기존 학습·검증 세션과 겹치지 않게 먼저 정합니다.
4. + 음성 파일 여러 개 추가로 시험용 녹음을 가져옵니다.
5. 실제 녹음을 듣고 정답·언어를 확인한 뒤 검수 완료를 체크합니다.
6. 초안·검수 자료 일괄 저장을 누릅니다.

이 폴더에서는 학습 점검이나 학습 시작을 누르지 않습니다.
평가만 하는 경우에는 세션 1개, 녹음 1개부터도 실행할 수 있습니다.
저장하면 평가 폴더에 manifest.jsonl이 생기고 음성은 audio 폴더에 보관됩니다.
폴더에 녹음 파일만 복사해 두는 것과 정답·검수 등록은 다른 작업입니다.

등록을 마치면 앱의 자료 폴더를 원래 학습 폴더로 돌려놓으세요.
평가용 녹음은 이후 추가 학습에도 넣지 않고 별도로 보관합니다.


[6] CMD를 올바른 폴더에서 여는 방법

1. 탐색기에서 start_learning.bat, app.py, requirements.txt가 보이는 폴더를 엽니다.
2. 탐색기에서 Ctrl+L을 누릅니다.
3. 주소창에 cmd를 입력하고 Enter를 누릅니다.
4. 새 CMD 창의 현재 경로가 앱 폴더인지 확인합니다.

아래 명령으로 Python 실행 경로를 확인할 수 있습니다.

.\.venv\Scripts\python.exe --version

맨 앞의 .\도 명령의 일부입니다. 현재 폴더를 뜻합니다.
그 뒤의 .venv는 설치 환경 폴더 이름입니다.
지정된 경로를 찾을 수 없다고 나오면 현재 폴더부터 확인하세요.
설치용 CMD는 명령이 끝난 뒤 닫아도 됩니다.
앱을 실행하면서 함께 열린 검은 창은 앱 사용 중 유지하세요.


[7] 새 시험용 샘플로 학습 전후 비교하기

아래 명령의 전제:
  - 학습이 정상 완료되어 있습니다.
  - 기본 학습 자료 폴더 data\my-voice를 사용했습니다.
  - 따로 빼둔 평가 폴더에 정답·언어·검수가 저장된 manifest.jsonl이 있습니다.

이 명령은 기본 학습 폴더에 기록된 최근 성공 모델을 사용합니다.
다른 학습 자료 폴더에서 학습했다면 경로를 그 폴더에 맞춰야 합니다.

앱 폴더에서 연 CMD에 다음 한 줄 전체를 복사하고 Enter를 누릅니다.
메모장에서 길게 줄바꿈되어 보여도 명령 전체가 실제로는 한 줄입니다.

.\.venv\Scripts\python.exe -c "import json,subprocess,sys,tkinter as tk;from pathlib import Path;from tkinter import filedialog;from uuid import uuid4;s=json.loads(Path('data/my-voice/.lvit-app.json').read_text(encoding='utf-8'));w=tk.Tk();w.withdraw();p=filedialog.askopenfilename(title='평가 자료의 manifest.jsonl 선택',filetypes=[('평가 목록','*.jsonl')]);w.destroy();p or sys.exit(0);subprocess.run([sys.executable,'evaluate.py','--data',p,'--adapter',s['adapter'],'--output','reports/new-test-'+uuid4().hex[:8]+'.json'],check=True)"

파일 선택창이 뜨면 평가 폴더의 manifest.jsonl을 선택합니다.
녹음 파일이나 .lvit-review.json을 선택하는 것이 아닙니다.
원본 Whisper small과 학습한 모델을 같은 시험용 녹음으로 순서대로 비교합니다.
이 과정은 평가이며 모델을 추가 학습하지 않습니다.

작업이 끝나면 다음 형식으로 결과가 나옵니다.
  CER: 학습 전 오류율 → 학습 후 오류율
낮을수록 좋습니다. 이 지표는 공백·문장부호·대소문자 차이를 제외합니다.
서로 같은 점수라면 그 평가 자료에서는 개선이 확인되지 않은 것입니다.

상세 결과는 앱 폴더의 reports 안에 new-test-로 시작하는 JSON 파일로 저장됩니다.
  references: 정답 문장
  baseline.predictions: 원본 모델의 인식 문장
  adapted.predictions: 학습 모델의 인식 문장
  training_info: 자료 수와 최종 선택된 학습 시점

같은 평가 자료로 반복 비교해야 학습 회차 간 개선을 판단하기 좋습니다.
시험 녹음 자체를 바꾸면 이전 보고서의 숫자와 바로 비교하지 마세요.
언어 설정이나 정답을 정정했을 때는 두 모델 모두 정정된 같은 자료로 다시 평가합니다.


[8] 오래된 평가 파일과 정답 수정에 관한 주의

prepared 안의 test.jsonl은 학습 준비 시점에 만든 평가 목록 사본입니다.
앱에서 정답·언어를 수정하고 저장해도 예전 prepared 파일까지 자동으로 바뀌지는 않습니다.
이 설명서 [7]은 별도 평가 폴더에 방금 저장한 manifest.jsonl을 직접 사용합니다.

과거 잘못된 언어 설정을 평가 사본에서만 정정했다면,
예전 prepared/test.jsonl을 다시 평가할 때 옛 설정이 재사용될 수 있습니다.
이전 보고서는 보관하고 현재 정답·언어가 맞는 평가 자료로 비교하세요.

이미 검증·평가로 분리된 자료의 정답·언어·세션을 수정한 뒤 이어 학습하면,
기존 분할 보존 검사에서 오류가 날 수 있습니다.
이 경우 기존 분할을 삭제해 해결하려 하지 말고 오류 내용을 확인해야 합니다.

학습/체크포인트 선택에 사용한 자료라는 평가 오류가 나오면:
  평가 녹음 또는 세션 이름이 학습·검증 이력과 겹치는지 확인하세요.
  학습에 쓴 파일의 이름이나 세션만 바꿔서 평가에 다시 사용하지 마세요.


[9] 설치가 필요한 경우에만 보는 명령

이미 학습이 성공한 환경에서는 아래 설치를 반복할 필요가 없습니다.
같은 폴더의 .venv를 유지하면 설치된 패키지도 유지됩니다.

처음에는 Python 3.11을 설치하고 setup_learning.bat을 실행합니다.
설치 완료 후 start_learning.bat으로 앱을 엽니다.
Python 설치 첫 화면의 Add python.exe to PATH를 체크합니다.

자료 입력용 설치와 실제 학습 패키지 설치는 구분됩니다.
GPU에 맞는 PyTorch를 먼저 설치한 뒤 학습 패키지를 설치합니다.
아래 첫 번째 명령은 예전에 안내한 GTX 1050 Ti용 CUDA 11.8 / PyTorch 2.6 조합입니다.
현재 학습이 되는 PC나 다른 GPU에 무조건 다시 적용하지 마세요.
GPU를 교체했다면 PyTorch 공식 안내에서 해당 GPU를 지원하는 빌드를 확인합니다.
https://pytorch.org/get-started/locally/

1. 기존 GTX 1050 Ti용 조합을 새로 설치하는 경우에만:

.\.venv\Scripts\python.exe -m pip install --upgrade --force-reinstall torch==2.6.0 --index-url https://download.pytorch.org/whl/cu118

2. GPU에 맞는 PyTorch 설치가 끝난 뒤 학습 패키지 설치:

.\.venv\Scripts\python.exe -m pip install -r requirements.txt

각 설치는 명령 입력 줄이 다시 나타나고 오류 없이 완료될 때까지 기다립니다.

설치된 PyTorch와 GPU 인식 확인 명령:

.\.venv\Scripts\python.exe -c "import torch;print('PyTorch:',torch.__version__);print('GPU available:',torch.cuda.is_available());print(torch.cuda.get_device_name(0) if torch.cuda.is_available() else 'CPU')"

requirements.txt는 학습용 패키지입니다.
requirements-export.txt는 학습용과 모델 내보내기용 패키지를 함께 포함합니다.
현재 학습과 위 평가에는 requirements.txt로 충분합니다.


[10] 보관해야 하는 파일과 업데이트

기본 학습 폴더 data\my-voice 안의 역할:
  audio: 변환된 음성 파일
  .lvit-review.json: 미완료 항목까지 포함한 전체 정답·세션·검수 목록
  manifest.jsonl: 검수 완료 자료 목록
  prepared: 학습·검증·평가 분할 사본
  runs: GUI에서 실행한 학습 결과와 best 모델

앱 폴더의 data 전체와 별도로 만든 평가 폴더를 함께 보관하세요.
CLI로 별도 위치에 학습 결과나 exports를 만들었다면 그 폴더도 보관합니다.

  - 앱과 실행창을 종료합니다.
